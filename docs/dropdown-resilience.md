# 下拉、浮层与提交闭环

本次优化沿用 `popup-controller.js` 的 `begin/inspect/closed` 和 `combo-agent.js` 的 `open/options/search/choose`。方案中的 `findOwner/openDropdown/verifyAndClose` 并非本分支的实际函数名。

## 浮层观察与稳定等待

- 点击前建立 DOM 可见性基线，观察新增子树、样式、ARIA 和文本变化，涵盖可访问的开放 ShadowRoot。已定位控件位于弹窗中时，允许在同一弹窗内操作。
- 除 ARIA 和组件类名外，支持当前控件内部的重复选项结构，以及新出现、靠近触发器、具有选项结构的未知浮层。时间相关性不足以单独证明归属；同时出现两个无法消歧的候选时继续停止。
- 排除控件已选值显示层、其容器和占位文字。公开 Phoenix 组件回归中曾复现选中回调已执行，但显示层被认成弹层、读回为空的情况；此规则避免把提交结果再次当成待关闭菜单。
- 扫描时登记已经展开或明确声明正在展开的控件，在打开新控件前逐个安全清理已有归属的菜单；CSS 可见但还没有高度的旧异步列表也进入点击前基线，避免它稍后加载时被认成下一次点击的新弹层。
- 等待选项文本、数量、几何位置和动画样式连续稳定 140ms，并检查面板自身及子节点的 loading/aria-busy 状态。观察器唤醒与短轮询共同处理节点变化和纯 CSS 动画，所有等待均有上限。
- 控件结构采集复用结构识别。只读导出可以包含已经打开的候选面板，并明确标记归属未确认，便于诊断，不把候选自动当成当前控件的面板。

## 选项查找与级联

- 标准语义和已知组件选项优先；缺少这些证据时按重复兄弟节点的标签结构、短文本和高度发现选项。过滤禁用、隐藏、分组标题及表单动作；不遍历全页文字找同名项。
- 当前列表没有目标时先搜索。输入框展开后变为可编辑也可识别，搜索使用完整目标；启用浏览器输入时走 CDP，普通 DOM 模式使用原生 setter 和 InputEvent。
- 非搜索列表按滚动容器高度的 80% 前进，等待渲染后重新读取当前 DOM。选项判断考虑内部裁剪，静态长列表中尚在屏幕之外的选项仍可经安全滚动定位；不把首次 DOM 当成完整虚拟列表。
- 水平且不重叠的选项列用于级联，按目标中明确提供的 `/／>＞→` 路径从左向右处理。父项点击后必须观察到对应子列更新，才继续子级；不推测资料未给出的层级。
- 明确声明多选或具有选项复选状态时，分别验证每项选中状态，最后核对所有目标读回。普通单选不根据装饰性的复选框图标猜成多选。
- 每级最多 70 次观察/滚动迭代，整体查找预算 25 秒。不会无限滚动或反复请求 AI。

## 点击、提交与恢复

- CDP 模式保留文档身份、唯一节点、位置稳定和命中点检查。列表内使用最小滚动，减少虚拟行在点击前被重建；节点被替换后重新定位，禁止复用失效引用。已定位的开放 ShadowRoot 内目标也参与令牌查找、命中与焦点验证。
- DOM 模式校准到目标内部实际命中的元素，发送带坐标的 pointer/mouse 事件链。合成事件仍然不是可信用户事件，要求可信输入的站点需要浏览器级输入。
- 选中后先等组件自然收起并读回，不再主动 blur 或向 body 派发盲目 mousedown。需要恢复时使用 Escape、明确的组件内关闭能力、经命中检查的触发器；安全外部点击只用于失败恢复，不用于把未提交搜索词变成成功。
- 选项未提交与弹层恢复失败分别保留。弹层归属不明或无法确认关闭时继续暂停相关操作。

## 本地等价规则与 AI

枚举沿用统一的 `ai-helpers.js`，使原生选择、自定义下拉和来源校验共享规则，避免在平台映射文件另建一套词典。增加政治面貌、英语考试等级、院校性质和层次的明确同义写法；学历和学位仍分开，学位推导学历仍要求原有的记录来源证据。不会把本科自动限定成全日制本科，也不会把 985、211、双一流当作同一事实。

普通下拉在本地匹配、搜索和滚动未命中时，可对当前已观察的候选做一次 AI 等价选择。请求只有字段名、目标和候选索引/文字，不附 DOM 或整份简历；返回索引必须存在，等待期间列表改变则拒绝旧索引。枚举和日期部分继续使用本地确定规则。不会用子串或 LCS 相似度自动选中不同的编号、专业大类或更具体的事实。

当前候选不代表远程字典或虚拟列表的全部内容。封闭 ShadowRoot、没有明确提交证据的自研多选、没有选项结构证据的单个纯 div 结果仍可能需要采集和人工处理。此改动扩展了已定位控件的交互，不代表字段扫描器已能扫描所有 ShadowRoot 表单。

## 验证

新增 `npm run test:choice-resilience` 使用生产 CDP 通道覆盖无类名浮层、超过两秒的异步加载、Loading 中残留旧选项、局部容器、展开后解除 readonly、虚拟列表、分列级联及无效父级点击、多选、自然关闭与失焦回滚、AI 索引过期、两个候选浮层、无关浮层、弹窗、开放 ShadowRoot 和 DOM 事件链。

同时运行现有单元测试、真实发布的 Phoenix 3.3.55 组件、Phoenix 日期与整轮填写、飞书 UD、普通下拉、自动补全、拆分年月、浏览器输入和结构采集回归。测试夹具及公开组件的通过不能代替登录后的招聘页面复测。
