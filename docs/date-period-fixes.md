# 0.8.1 日期区间与获奖归属修复

- 已知 period 日期组件若有两个明确的可见年月位置，将它们分别登记为开始、结束字段，排除内部隐藏输入。无法唯一识别仍停止，不盲点。
- 读回时不再把数字年月当作占位符。
- 单日期隐藏输入的打开动作指向可见日期容器；年份精度面板单独选年并核对。
- 重复获奖条目用奖项名称字段校正板块；扩充常见获奖标题。
- 含日期的重复记录整体重新匹配，避免快照拿走名称后导致日期失去来源锚点。
- 字段对照表保留来源校验拦截原因。

验证：73 项单元测试及浏览器表单回归；新增隐藏输入/双可见端点、获奖归属、年份选择模拟用例。没有实际招聘页面 DOM，也未在真实招聘页面端到端验证。浏览器输入实验开关仍可选。
