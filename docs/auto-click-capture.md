# 自动点击采集控件结构

在侧栏「采集控件结构（排查日期、下拉问题）」里点「自动点击采集（优先上次没填上的控件）」，插件会自己把控件挨个点开并记录结构，跑完后照旧点「完成并导出诊断文件」。目的是省掉手动一个个点：0.8.3 的飞书日期适配就是照用户导出的采集文件写的，这类文件是上游补站点适配的唯一依据。

目标来自上一次填写的结果：写入失败、读回不符、标签不可信或没有标签的自定义控件优先，其余**页面上还没有值**的自定义控件其次（已经有值的不再采，免得挤占有限的点击名额）；这一页没跑过填写时直接扫页面上的自定义控件兜底。只采组合框与日期控件——单选/勾选点下去会改掉用户已经选好的值，原生 `<select>` 弹的是系统下拉、CDP 关不掉，都不在名单里。一次最多点 7 个控件（7×3 张快照，给 24 张上限留出「导出前」的位置），循环硬预算 90 秒，自动开启的采集会话死线 120 秒。

点哪里和填写时保持一致：组合框点触发器；日期控件只有隐藏 input 时才点外层容器，有可见 input 就点 input——点容器正中心可能落在空白处或日历图标上，面板根本不会打开。判定「可见 input」要连 opacity 一起看：组件内部的隐藏 input 常常还有 8×6 的实际盒子，只按尺寸判会把它当成可点节点，点下去只会把焦点挪进去、什么也不发生。

长表单里目标常在几千像素之下，而 CDP 的点击坐标是 `scrollIntoView` 之后立刻读的：页面还在滚，坐标就是废的，点下去落在空处（真实采集文件里 y=5659 的获奖时间控件就是这么漏掉的，事后看焦点都没动）。所以每个目标点击前都先滚到视口中央、按节点自身 rect 等滚动停稳（内层滚动容器也算），停稳后仍不在视口内的记 `offscreen`，不假装点过。

点击方式跟着侧栏的「真实浏览器输入」开关走：勾选时用 CDP 发真实点击（这类组件普遍拒绝合成点击），没勾时退回合成事件。用了哪种会写进导出文件的 `autoClick.clickKind`——「合成点击打不开面板」本身就是诊断结论。每个控件记录「自动点击前」「自动点击后 350ms」「自动点击后 1300ms」三张快照，快照带 `auto:{index,control,reason,clickKind,opened,focusInside}`；顶层 `autoClick` 汇总计划数、点击数、**打开面板数** `panelsOpened` 和每一个被跳过的控件及原因。点了却没打开面板是上游最需要的信号，所以和点击数分开记。导出文件的 `kind` 与 `schemaVersion` 不变，手动采集的文件不含这些新键。

采完一个控件要把它打开的弹层关掉再采下一个，顺序是 Escape → 失焦 → 点外面：飞书的树形下拉只发 Escape 关不掉，必须失焦（填写路径关日历用的也是 Escape + blur）。关不掉记 `panel-stuck` 并继续。另外，采集前就已经开着的浮层不会因为之后的属性变化被算成当前控件的弹层——否则上一个控件没关掉的面板会混进后面每一张快照，导出文件里就分不清归属。

安全边界：全程只点开，不选值、不输入文本、不提交。疑似动作类控件一律跳过并记录原因（`denylist` / `would-modify-data`）：submit 按钮与 image 输入、带 href 的链接、单选/勾选框、标签含「同意/协议/承诺」的控件，以及按钮或链接文本以「提交、保存、下一步、投递、删除、清空、重置、取消、退出、登录、授权、同意…」及英文同义词开头的控件。真实点击落在元素矩形正中心，所以中心上盖着的节点（例如日期控件自带的「清空」）会按命中点再判一次，且这个判断在滚动停稳之后做——离屏元素的中心坐标会被钳到视口边缘，先判等于没判。其余跳过原因：`stale`（节点已被页面替换）、`hidden`、`offscreen`、`no-root`、`click-failed`、`panel-stuck`（弹层关不掉）、`budget`（超出数量或时间预算）、`session-ended`。跳过都不是静默的：状态行给计数，明细在导出文件里。

脱敏与上限和手动采集完全一致（见 [控件结构采集](control-capture.md)）：走同一份序列化代码，同样是 24 快照 / 600 节点 / 深度 12 / 4 弹层，输入框值照样清除，不发往模型或服务器。`label-was-value` 那类字段的标签不进文件，只留类名线索。自动模式下 Escape 只用于关弹层，不会停掉采集会话；交回手动模式后 Escape 照常停止。

验证：`npm run test:autoclick`（tests/auto-click-capture.cjs）分四段。A：自动模式下 Escape 不停会话、交回手动后仍会停。B：用真代码验证目标挑选——写入失败与读回不符的排在前面，隐藏 input 的日期控件点容器、有可见 input 的点 input，单选与已有值的字段被排除，标签不可信的不带标签。C：走真实侧栏按钮跑完整流程，真实 CDP 与合成两条路径各一遍，断言只认真实点击的弹层被采到、点 input 才开的日期面板被采到、只认失焦关闭的面板也能关掉（`panel-stuck` 为 0）、任一快照不同时含两个弹层、四类危险控件点击计数为 0 且都记在 `targetsSkipped`、超出 7 个的记 `budget`、`panelsOpened` 与 `clickKind` 如实。D：首屏之外 4000px 的控件在平滑滚动下照样点得开（去掉滚动等待这条就会失败）。未覆盖：真实招聘站点的组件行为、真浏览器里的 chrome.debugger 信息栏与权限、iframe 与封闭 Shadow DOM。
