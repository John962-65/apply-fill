# v0.8.2 控件结构采集

v0.8.20 修正了 UD/Formily 字段边界：布局的 `control-align-left` 不再被当作控制层，真实外层字段和本地标签能够进入快照。学校输入框的 `dropdown-open` 状态包装不算弹层；打开前的快照不再被后续统计回填为“已打开”。

v0.8.19 的「自动展开控件并导出诊断文件」会挑选不同控件类型，逐个展开、记录、收起，完成后直接下载 JSON。开启「实验：浏览器层点击与输入」可使用真实点击与 Escape。输入框值会移除，导出不自动上传。UD/Formily 控件同时记录有边界的字段标签与完整选择器，避免只有输入框、没有字段名或弹层的文件。

v0.8.18 新增「直接导出当前控件结构（无需点击网页）」。菜单卡住时点击该按钮即可导出现场，不需要再操作网页控件；已有输入值不会被改变。输出保留外层 Dropdown 与内部并列菜单，最多 24 张快照，输入值在文件中移除，不自动上传。

在侧栏展开「采集控件结构（排查日期、下拉问题）」，点「开始采集控件结构」，再点击网页中的一个问题日期框或下拉框，展开面板。可以切换年月或展开选项，也可点「补采当前面板」。最后点「完成并导出诊断文件」，上传下载的 JSON 文件即可。

一次采集一个控件。重新开始会清空本次记录。按 Escape、点停止、满 60 秒或达到 24 次快照都会停止自动采集；已采集内容仍可导出。采集不需要启用浏览器输入实验开关，也不自动填值或提交表单。

内容包括点击前/后结构、异步弹窗、标签/类名/角色、尺寸、可见性、指针事件属性、中心点命中节点、焦点、隐藏输入和有限祖先结构。最多 24 个快照，每个树集合最多 600 个节点、深度 12、弹层 4 个；标记截断。

输入框 value、文本域内容、可编辑区域内容不导出；不复制脚本、任意 data 属性、事件代码、链接或页面查询参数。页面显示文字、类名、占位文字仍可能含个人信息，导出前可预览。结果只在当前页面内存与用户下载文件中，不发往模型或服务器。当前不进入 iframe 或组件的封闭 Shadow DOM。

验证：73 项单元测试；已有表单回归；新浏览器测试覆盖异步弹层、隐藏输入、输入内容清除、范围限制、下载、停止/重启/Escape、24 次上限及实际侧栏按钮绑定。Chrome API 用测试替身，DOM 与下载使用真实浏览器。此版本增加取证功能，不宣称修复招聘网站日期填写。
