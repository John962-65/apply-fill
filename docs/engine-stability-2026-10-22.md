# 真实招聘网站填写引擎专项修复

基线：`a4cad2e`，分支：`v2.0`。本轮沿用原有调度、身份、Guard 和执行器，没有新增独立 Agent 或字段匹配规则。

## 修复范围

- **跨波次重规划**：Wave 前后记录 DOMRevision，并对比节点引用、字段增删、值、选项、禁用/只读和约束。每个 Wave 后按最新计划重新分组，而不是等到全部波次结束才检查新增字段。重新绑定包含教育、工作、项目实例。每字段最多参与三次波次执行，每轮步骤调度最多重建九次计划，外层步骤发现也有独立次数上限；耗尽预算转人工。
- **逻辑身份与保护**：同次运行、同节点且证据未冲突的实例可保留连续身份；完整重绘按唯一稳定标识或原文见证重定位。不能证明身份时保留歧义。用户接管状态跟随逻辑字段键；浮层选项与搜索框的可信用户事件归属其触发字段。新建实例在同次运行重扫后仍报告新建，歧义实例不会被同 ID 的缺失报告覆盖。
- **正式提交**：业务隐藏值优先于显示标签；存在空业务值时不退回显示值。搜索文本、浮层关闭和点击已发出均不能单独证明提交。选项编码只有来自实际匹配候选时才能用于业务值验证。未稳定或无法观察正式状态时返回 UNKNOWN。
- **交互**：普通下拉框优先原生 `click()`，无可观察进展时最多补一次 Pointer/Mouse 序列；Pointer 事件使用 PointerEvent。搜索、打开、候选选择和等待提交分别记录结果。日期导航继续按实际进展等待，服从字段预算。拒绝非可信事件的组件转人工，不伪造 `isTrusted`。
- **诊断与结果**：字段诊断覆盖 SCAN、MAP、FORMAT、LOCATE、OPEN、SEARCH、SELECT、WAIT_COMMIT、VERIFY、REANCHOR、RECOVER。缓冲最多 4,000 条，并报告截断量。SidePanel 的“复制脱敏诊断报告”仅导出白名单元数据和原因码，不导出简历、目标值、提交证据正文、API 设置或错误响应正文。存在人工待处理项或用户清空必填项时汇总为 PARTIAL；用户保护不等于必填校验通过。跨帧和单字段修正保留该状态语义。
- **人工操作收尾**：浮层重试、换来源等待执行与后台事务锁一同结束，再恢复可操作状态；摘要更新同步刷新字段行，防止旧行覆盖人工核对结果。用户事件过滤穿透插件自身 Shadow DOM，同时继续识别网站 Shadow DOM 中的真实编辑。

## 可复现验收

新增靶场：`packages/testbed/engine-regression.html`；测试：`packages/testbed/e2e/engine-regression.spec.ts`。

覆盖整段 React 重绘但字段数量不变、教育经历换位、重绘后的用户编辑保护、仅值重置、仅选项变化、重规划预算、1/10/11/12 精确月份、显示成功但业务未提交、浮层关闭但值未提交、点击无响应、仅响应 PointerEvent、拒绝非可信事件、预先打开的浮层、执行期间用户接管，以及诊断阶段与脱敏复制。

原有重复经历竞争认领、SPA 步骤切换、事务撤销、隐私和迁移测试保留。原有测试中“存在人工待处理仍为 COMPLETED”的断言改为 PARTIAL；波间已修复的值重置改为检查真实的重复写入诊断，最终 dirty sweep 应干净。60 ms 日期预算用虚拟时钟证明，避免机器负载影响首次点击次数。

验证命令：

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm lint:boundaries
pnpm build
pnpm test:e2e
APPLYFILL_E2E_BROWSER=edge pnpm test:e2e
```

## 验证边界

浏览器回归使用本地 React/Vue 靶场与匿名测试资料。模型相关回归使用模拟 API，不代表真实模型调用验证。本轮没有在用户登录的 Moka、北森或其他招聘站点填写或提交申请；真实 ATS 的地区/学校远程候选、依赖可信输入的组件及站点改版仍需用户本地验证。缺少正式提交证据或逻辑绑定证据时继续转人工。
