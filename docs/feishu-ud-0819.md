# v0.8.19 飞书 UD 控件与日期确认

用户提供的蔚来飞书网页结构包含 24 张只读快照：UD 下拉搜索输入框及其父层设置了 `pointer-events: none`，外层 `.ud__select__selector` 才是点击面。日期包含 `.ud__picker` 和 `.throne-biz-date-range-picker-input`。文件没有展开的选项或日历面板；通过实际 URL 打开简历页会跳转登录，当前未验证登录后的完整弹层。

## 修改

- 下拉框使用外层选择器，打开面板后仅选择有来源、唯一匹配的选项。选项点击后必须保留选择结果，搜索文字不计入成功。
- 使用 UD/Formily 的字段边界取标签。找不到本字段标签时保持空白，不借用前一个姓名或学校标签。日期输入包装用的 `label.ud__input-input-wrap` 不当字段名。
- 电话字段的区号选择器标为手机区号，实际电话输入框保留手机号标签；完整手机号不允许写入区号字段。
- 浏览器输入操作绑定消息发送页的 tabId 与唯一 DOM 标记，支持非前台标签页。忽略单纯 hash 变化；路径、查询参数变化或导航中断时停止。每个真实输入动作前检查目标页面地址，保留遮挡、节点替换与焦点校验。
- UD 日期走“打开关联面板—读取日期格/有语义的导航按钮—选择—确认—核对”流程。只使用当前框明确关联、或打开后唯一出现的日历。支持明确年月/日期标记、年份与月份列表和可确认的翻页按钮；布局没有足够语义时停止并提示采集。确认按钮只点击一次；面板未提交、值被撤回、归属不唯一、另一端日期被修改时不报成功。失败留下的草稿不用于资料回收。
- 日期精度由实际控件决定。`YYYY-MM` 使用年月；网页要求日而来源只有月时沿用精度补齐提示，原始资料不修改。
- 获奖描述可以由本条已确认记录的明确奖项级别、获奖等级组成，保留所有来源编号；缺失项不编造，跨记录、冲突或多余事实仍停止。
- 自动诊断优先挑不同控件，避免多段相同日期挤满采集配额。每个控件记录完整外壳、所属字段及打开后的弹层，完成后直接导出，真实 Escape 能收起不带输入框的 div 触发器。采集只展开，不选择或填值。

## 验证范围

`tests/fixtures/feishu-ud.html` 的输入框类名和指针事件来自用户文件；外层 Formily 标签与弹层行为是匿名复现。真实 Chromium/CDP 验证了正确点击层、年月选择与确认、确认被拒绝、候选不提交、重复面板、控件重渲染及另一端日期变化。测试日历使用可验证的语义标记，不代表已经获得蔚来私有日历 DOM。

此外运行浏览器输入、结构采集、一键诊断、来源归属、sd 下拉、Phoenix 填写及已发布的 Ant Design / Element / iView / React Select 组件回归。浏览器层非前台输入测试使用两个真实标签页，确认另一页的人工内容和点击计数不变。

## 更新与继续诊断

解压 `apply-fill-v0.8.19.zip` 覆盖原扩展目录，在扩展管理页重新加载，再刷新招聘网页，确认显示 0.8.19。扩展 key 与存储格式不变，旧资料树不需要重做。

在蔚来简历页保持「实验：浏览器层点击与输入」开启，再跑填写。若日期面板仍未识别，在侧栏展开「采集控件结构（排查日期、下拉问题）」，点「自动展开控件并导出诊断文件」，把下载的 JSON 提供给开发者。文件会移除输入值，页面文字仍可能含个人内容，可先预览；不会自动上传。直接只读导出也保留，适合无法再展开的情况。
