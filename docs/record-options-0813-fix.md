# v0.8.13：校园日期与下拉选项对应

本版在 v0.8.12 的标准资料树和人工核对流程上修复填写问题。原有模板、资料树、字段编号和用户修改不自动重建。

## 校园经历的日期

校园表单可能只有职务、起止时间和描述，没有组织名称。两条记录都叫“干事”时，单凭职务无法确认是哪条经历。上一版在职务校验中使用了唯一的描述，但日期校验仍只查组织或职务，导致资料已有日期却被拦截。

本版在没有名称锚点时，允许经过原文校验、用途正确且只能属于一条记录的描述确认归属。日期还须来自同一条记录，开始和结束方向仍分别检查；相同日期或相同职务不能证明记录归属。两个候选、跨条目日期、重复的通用描述与来源冲突继续停止。

## 获奖级别与语言等级

| 网页字段 | 明确的同义写法 | 处理方式 |
| --- | --- | --- |
| 获奖级别、奖项级别 | 校级、院校级、学校级 | 从当前控件的实际可用选项中唯一匹配 |
| 获奖级别、奖项级别 | 省级、省区级 | 同上 |
| 获奖级别、奖项级别 | 国家级、全国级 | 同上 |
| 学历 | 本科、大学本科；硕士、硕士研究生等 | 限定同一用途，学位不替代学历 |
| 听说、读写、掌握程度 | 良好与熟练、精通、母语没有预设对应 | 保留资料值，列出实际选项，请本人选择 |

已识别的上述等级字段通过本地观察、选择、读回完成确定操作，不再依赖模型决定是否点击明确等价项。其他复杂下拉继续使用逐步 AI 交互，日历仍使用现有日期驱动。

两个等价选项同时存在时停止。禁止选择禁用项、占位项或不同等级。选中后仍须核对最终显示值和重新渲染后的值；页面丢弃选择不计成功。

“资料值没有等价选项”在对照表中显示为“需要人工选择”，附资料值和网页选项，不再归为“写了但页面没认”的控件故障。

## 资料核对

- 学历与学位分别维护。例如本人核实为本科后，学历填“本科”，学位可填“工学学士”；只提供“学士”不自动推断本科学历。
- 奖项名称含“全国”不自动改变已有奖项级别。请按照证书或颁奖说明确认级别，另用获奖等级保存一等奖、优胜奖等。
- 语言的掌握程度、听说、读写各自确认。网页采用另一套等级时，按自己的实际能力人工选择，再使用补充采集核对保存。
- 意向、薪资、证件号码等空白项按本人需要补充；没有实习经历不虚构记录。

覆盖原扩展目录后，在扩展管理页重新加载，确认版本为 0.8.13，再刷新资料管理页与招聘页面。已有资料无需重新上传。

## 验证

验证使用生产扫描、来源校验和填写代码，浏览器操作经真实 CDP 输入通道执行。自动用例采用匿名资料和公开 Phoenix DOM 形状，没有连接模型服务或登录招聘网站。

- 126 项单元测试：包含两条同职务校园记录、四个同值日期、描述冲突、重复通用描述、跨条目日期、禁用与重复选项。
- 实际上传的资料形状回放：222 个字段、170 个非空字段、3 条校园记录。前两条校园记录的四个日期在原代码中全部被拦截，本版全部通过来源校验。实际文件只用于临时验证，不进入源码或插件包。
- `tests/phoenix-fill.cjs`：一键填写完整链路，核对四个校园日期、四个项目时间端点、多次同名获奖、原有内容保护和最终 DOM 值。
- `tests/phoenix-enums.cjs`：两种公开选项结构、校级/院校级、原生下拉读回、语言等级不匹配、重复选项、重新渲染、页面延迟丢弃选择及故障分类。
- `tests/combo-browser.cjs`、`tests/form-browser.cjs`、`tests/phoenix-browser.cjs`：异步选项、联动、重新渲染、相邻日期与值丢失保护。
- `tests/browser-smoke.cjs`：标准资料树、原句引用、核对草稿、暂存、保存、备份及窄屏管理页。

这说明已复现的问题在测试覆盖的结构中修复；真实平台改变 DOM、校验或事件规则后仍可能需要新结构样本。
