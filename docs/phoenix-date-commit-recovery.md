# Phoenix 日期提交与恢复

Phoenix 月份和日期格先定位到格内唯一、可见、可用的交互元素，再经浏览器输入通道点击。月份格存在内部 `.phoenix-calendar-month-panel-month` 时会点内部元素；找不到唯一交互目标就停止，不猜测外层格的事件绑定。

点击后观察日期读回、弹层关闭、视图切换和唯一的确认按钮。只在读回值符合目标精度时报告选择成功；发现明确的确认按钮时才继续点击确认。提交等待有上限，读回失败记为 `OPTION_COMMIT_UNCONFIRMED`。

Phoenix 弹层按 Escape、唯一的组件内关闭控件、安全区域点击的顺序恢复。组件仍打开时不再点击可能被弹层遮挡的原触发器，而是记为 `POPUP_CLOSE_UNCONFIRMED` 并暂停相关复杂控件。交互结果同时保留主故障和恢复故障；用户手动收起弹层后，可以再次点击“一键 AI 填写”继续补未完成字段，已有内容按原规则保留。

`npm run test:phoenix` 使用真实 Chromium/CDP 覆盖仅内部月份元素响应、显式确认、延迟提交、选择丢弃并遮挡触发器，以及手动关闭后重试和继续填写。它验证的是受控夹具，不代表已在登录后的招聘页面复现或确认具体事件绑定。
